Base a137f18. Six distinct procedural sound generators: GRIT filtered noise, CRUSH saturated impact, FRACTURE sample-hold quantization and gated stutter, METAL SKIN FM/inharmonic partials, SUB PRESSURE saturated low oscillator, EROSION overlapping windowed procedural grains with bounded short feedback. Shared AudioEngine voice bus, compressor/ceiling, analyser and watchdog; no separate context or tracker. Preset GRIT default, explicit user activation; original five V1 presets retained. Distorsi/Tekstur/Ruang/Volume; test uses same preset PCM with explicit synthetic event. Contact uses detected-estimate/video/simulated qualification; slide/pivot use existing per-foot events, continuous movement only in Garis; bounded density per actor and limited polyphony. Spatial pan per material voice; existing room/filter shared. No pressure measurement; no automatic inference of hesitation or stomping force. No sampled granular corpus, only procedural grain windows. No independent per-actor preset assignment, full advanced mapping rack, replay, recording or Perform yet. Blackout/hidden tab/source loss retain V1 safety gates; source change discards prior events. QA covers pure PCM and browser test signal for six presets plus legacy path and blackout. Physical listening, speaker calibration and live source validation remain pending. GitHub Pages first; no Vercel change.
